# Kỹ năng phòng marketing

Mỗi kỹ năng một thư mục `.claude/skills/<tên>/SKILL.md` (đặc tả Agent Skills; máy canh kiểm `name` trùng thư mục). Phiên
Claude mở ở repo này tự nạp.

| Kỹ năng | Dùng khi |
|---|---|
| `lich-y-tuong-tuan` | Lên lịch tuần: 4–5 video + 2–3 bài ảnh / chữ theo 5 trụ |
| `kich-ban-video-ngan` | Viết kịch bản video dọc + danh sách cảnh cho nhân viên quay |
| `bai-ke-chuyen` | Viết bài chữ / bài nhiều ảnh cho Facebook, Instagram |
| `doc-so-tuan` | Sáng thứ Hai: ghi số 7 ngày, xếp hạng, rút bài học, đề xuất bài nên đẩy tiền |

Vòng mỗi tuần: `doc-so-tuan` → `lich-y-tuong-tuan` → `kich-ban-video-ngan` / `bai-ke-chuyen` → Sếp duyệt → đăng.

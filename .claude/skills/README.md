# Kỹ năng phòng marketing

Mỗi kỹ năng một thư mục `.claude/skills/<tên>/SKILL.md` (đặc tả Agent Skills; máy canh kiểm `name` trùng thư mục). Phiên
Claude mở ở repo này tự nạp.

## Dòng chảy

```
nghien-cuu-thi-truong ─┐
nghien-cuu-doi-thu ────┴→ chien-luoc-marketing → lich-noi-dung → viet-bai ─┬→ lam-anh
                                giong-van ──────────────────────↗          └→ kich-ban-video
```

| Kỹ năng | Ra gì | Ở đâu |
|---|---|---|
| `nghien-cuu-thi-truong` | Báo cáo thị trường khách lẻ, có nguồn | `chien-luoc/nghien-cuu/` |
| `nghien-cuu-doi-thu` | Hồ sơ 3–5 đối thủ, bản đồ định vị, khoảng trống | `chien-luoc/doi-thu/` |
| `chien-luoc-marketing` | SWOT, chọn khách, định vị, 4P, 90 ngày | `chien-luoc/` |
| `giong-van` | Bộ giọng văn, từ cấm | `thuong-hieu/giong-van.md` |
| `lich-noi-dung` | Lịch tháng, mã bài | `lich-noi-dung/` |
| `viet-bai` | Bài nháp đúng khuôn | `bai/` |
| `lam-anh` | Ảnh Canva / Gemini, nhãn AI | ảnh ở Drive `LabbanMarketing`, bài ghi đường dẫn |
| `kich-ban-video` | Kịch bản, danh sách cảnh quay, cảnh Veo | `bai/` + Drive |

Mọi đầu ra là nháp, đi qua PR, Sếp duyệt. Không kỹ năng nào đăng bài hay bật chi tiền quảng cáo.
